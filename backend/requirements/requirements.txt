#
# ruff is PINNED EXACTLY, and this is the one pin that is not optional.
# `backend/pyproject.toml` names rules that only exist in recent ruff -- RUF033,
# RUF036, RUF043 and RUF059 among them -- and ruff rejects a config containing
# rule codes it does not know. The previous floor, `>=0.4.0`, therefore allowed
# an install on which the checked-in lint config would not even LOAD. Beyond
# that: ruff adds rules in every minor release, so an unpinned linter can turn a
# green repo red with no code change on our side, which is the exact recurring
# cost D13 and D26 exist to remove. 0.16.1 is the version the 364-error triage
# in roadmap D29 was performed against, so every count recorded there is only
# meaningful while this pin holds. Bumping it is a deliberate act: re-run
# `python scripts/verify_repo.py` and re-triage whatever the new release adds.
